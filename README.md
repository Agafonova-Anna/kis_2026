## Задача 3: Системное программирование

## Сборка и запуск

```sh
cmake -S . -B build
cmake --build build -j
```

Бинарники лежат в `build/bin/`:

```sh
./build/bin/server [порт]
./build/bin/client [host[:порт]] [имя]
```

## Команды

Клетки нумеруются 1–9 по строкам сверху вниз. Крестики (X) всегда ходят первыми. `<n>` — номер партии, в квадратных скобках указаны необязательные аргументы. На команду с неверным числом аргументов программа отвечает «Неверный формат команды».

Мобиус (сервер):

- `players` — варианты и их статистика
- `invite <имя> [me|loki]` — пригласить вариант; `me` — первым ходит Мобиус (по умолчанию), `loki` — вариант
- `games` — незаконченные партии
- `move <n> <клетка>` — сделать ход
- `show <n>` — состояние и ходы партии
- `history <имя>` — история игр с вариантом
- `quit` — выключить сервер

Вариант (клиент):

- `accept <n>` — принять приглашение
- `decline <n>` — отказаться от приглашения
- `move [n] <клетка>` — сделать ход; номер партии можно опустить, если незаконченная партия одна
- `history [n]` — ходы партии; без номера — текущая или последняя партия
- `quit` — выйти
